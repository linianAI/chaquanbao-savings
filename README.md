# 省钱技能「不能买贵」 chaquanbao-savings

把你的 AI 变成一个返利机器人：买东西之前先帮你查一遍优惠券和返利，把券后价和下单链接递到你手里，你自己下单付款。

数据来自找券宝（chaquanbao.pages.dev）：淘宝 / 京东 / 拼多多查券转链、外卖 / 电影票 / 打车 / 酒店优惠入口、全网羊毛线报。只查、只给链接，从不代下单、代付款。

## 怎么装

### 方式一：装技能（推荐）
把本仓库的 `SKILL.md` 导入你的 AI 即可：
- 豆包工作：在技能里添加本技能（粘贴 SKILL.md 内容或导入仓库地址）
- Claude Code / 其他支持 SKILL.md 的 Agent：把 SKILL.md 放进技能目录

装好后直接说人话就行，比如：
- "帮我查一下抽纸有没有券"
- "这个链接有没有返利"（把商品链接发过去）
- "点外卖有没有红包"
- "今天有什么羊毛"

## 两层实惠
1. **免注册**：查券拿券后价，10 块的东西 7、8 块到手，人人可用。
2. **注册后**：在找券宝注册账号，下单的返利现金会记到你的账号（买家返利 60%），可提现。

## 边界
- 只查券、只转链、只给入口链接；下单付款永远由你自己完成。
- 不会向你索要任何账号、密码或验证码；你发来的商品链接和需求只用来帮你查券。
- 你发来的关键词与商品链接会发送到服务端查询，请不要发送含订单号、收货地址、手机号的链接。
- 结果来自联盟推广商品池，不是平台全站，不代表全网最低价；查不到 ≠ 没有优惠。
- 返利是下单前预估，实际到账以订单结算为准。
- 目前支持淘宝 / 京东 / 拼多多大部分商品查券，以及外卖、电影票、打车、酒店等生活服务入口；个别商品没有券或没有返利，以实际查到的为准。
- 京东通道偶尔繁忙，查不到时先看淘宝 / 拼多多。
- 查不了的时候：多半是服务临时故障，过一会儿再试一次即可。
